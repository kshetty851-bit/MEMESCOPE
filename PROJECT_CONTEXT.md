# MEMESCOPE - Project Context

> Last Updated: July 2026

---

# Project Overview

MEMESCOPE is a production-grade AI crypto intelligence platform.

The goal is to discover newly launched Solana tokens, enrich them with on-chain and market intelligence, score them using AI, detect rugs, identify smart money, and present everything inside a premium AI observatory interface.

The project is built for scalability and will eventually support multiple blockchains.
