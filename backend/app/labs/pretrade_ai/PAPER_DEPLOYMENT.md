# Paper service deployment

The same `/pretrade-ai` page polls `/api/v1/labs/pretrade-ai/status`. A dedicated container waits 30 seconds between bounded scan cycles independently of the page. It validates every status request through the existing internal `/api/v1/alpha/session`; invalid cookies fail closed. No write endpoint exists.

Build the lab directory with `Dockerfile.paper`. Set `PRETRADE_READ_DSN` to a dedicated PostgreSQL login with SELECT only on grad_migrations, grad_tokens and grad_postgrad_samples, and default_transaction_read_only=on. Set `PRETRADE_STATE=/data/paper.sqlite3`; mount a persistent named volume writable by uid 10001. Set PRETRADE_RPC_URL to the approved read-only Helius endpoint and PRETRADE_QUOTE_KEY to the approved Jupiter quote key. These consume existing data-provider quotas. Do not supply signer, wallet or unrelated application secrets. Connect to the backend's private Docker network; do not publish its port to the host.

Caddy routes only `/api/v1/labs/pretrade-ai/*` to `pretrade-ai:8011`. The normal backend route is unchanged. Validate configuration before graceful reload. No wallet/worker container restarts are needed. The service is deliberately not added to application startup or existing strategy scheduling.

Rollback: stop the `memescope-pretrade-ai` container and restore the preceding Caddy file, then validate/reload. Preserve the paper volume. Other services remain running. Source review and frontend release are separate from the host-side service rollout.

Live evidence adapter (2026-10-14): matched $10 USDC buy and output-sized sell quotes; SPL / metadata-only Token-2022 authority checks; indexed holder balances aggregated by owner only when their total matches mint supply; confirmed PumpSwap event history through verified pool creation. History reads at most three pages of 100 transactions. Truncated logs, missing creation, unsupported extensions, incomplete holder coverage and provider failures remain unknown, never zero or safe. Public five-minute counts are never relabeled as lifetime swaps. Liquidity older than 30 seconds is omitted; matched quotes must be at most five seconds old. Quotes must include the candidate pool on both legs. Paper exits use the sell-side quote price with additional conservative paper cost assumptions.

The supplied rules and thresholds are unchanged. Fourteen of 21 features can be available when complete history includes both buys and sells in the 30-second window. No sellers means the ratio is undefined and omitted. Creator/funder history remains unknown, and no real-data-trained model is loaded. Every assessment exposes individual data-source failures on the existing page. Test fixtures demonstrate mechanics only, never market profitability.
