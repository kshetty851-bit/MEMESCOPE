# MEMESCOPE Design Bible

> Version 1.0

---

# Design Philosophy

MEMESCOPE is not a crypto website.

It is an AI-powered orbital observatory that continuously watches blockchain activity.

The experience should feel premium, futuristic and scientific rather than flashy or meme-like.

Every screen should reinforce the feeling that the user is inside a mission control centre orbiting Earth.

---

# Core Principles

The interface should always be:

- Elegant
- Minimal
- Professional
- Cinematic
- Data-first
- Calm
- Fast
- Accessible

Avoid unnecessary visual noise.

Never imitate casino-style crypto dashboards.

---

# Inspiration

Visual inspiration comes from:

- NASA Mission Control
- Interstellar
- Iron Man JARVIS
- Apple
- Linear
- Bloomberg Terminal
- Arc Browser
- Stripe Dashboard

Do not copy these products directly.

Use them only as inspiration for quality and clarity.

---

# The Living Universe

The background is part of the product.

It is never static.

The observatory exists in orbit.

Background layers include:

- Stars
- Nebula
- Galaxies
- Earth or Moon
- Orbiting station
- Satellites
- Asteroids
- Rockets
- Blockchain data streams
- Ambient particles

Movement should be extremely slow.

The background supports the story without distracting from data.

---

# Event Reactions

The universe reacts to real blockchain events.

Examples:

New Token
→ Rocket launch

Whale Activity
→ Blue energy ripple

Elite Gem
→ Golden pulse

Security Alert
→ Red warning wave

Quiet Market
→ Calm universe

Busy Market
→ Increased particles and data streams

All reactions must come from real backend state.

Never invent activity.

---

# AI Division

The platform is operated by specialised AI agents.

Scout
- Discovery

Titan
- Whale Intelligence

Oracle
- AI Analysis

Pulse
- Momentum

Sentinel
- Security

Echo
- Narrative

Apex
- Elite Certification

Current implementation uses animated sigils.

Future versions may replace them with premium 3D cyber characters.

---

# AI Core

The AI Core is the visual heart of MEMESCOPE.

It receives intelligence from every AI division.

It should:

- Pulse gently
- Show confidence visually
- React to major events
- Never become distracting

---

# Command Center

The Command Center is the primary workspace.

Priorities:

1. Clarity
2. Readability
3. Speed
4. Real-time information

Decorative elements must never reduce usability.

---

# Observatory Log

The Observatory Log records important AI actions.

Entries should come only from genuine backend events.

It should read like a mission log.

Example:

Scout detected new signal.

Titan confirmed whale activity.

Oracle increased confidence.

Sentinel cleared contract.

Apex granted Elite classification.

---

# Motion Language

Motion should communicate information.

Preferred animations:

- Fade
- Opacity
- Glow
- Slow rotation
- Soft scaling
- Parallax
- Energy flow

Avoid:

- Bounce
- Flashing
- Excessive shaking
- Distracting effects

---

# Colour Philosophy

Dark interface.

Cool blues.

Subtle cyan.

White typography.

Gold reserved exclusively for Elite events.

Red only for warnings.

Green only for confirmations.

---

# Typography

Readable.

Professional.

Comfortable spacing.

Large headings.

Consistent hierarchy.

Numbers should be easy to scan.

---

# Performance Rules

Target:

60 FPS.

Prefer:

- SVG
- CSS
- GPU transforms

Avoid heavy WebGL unless clearly justified.

Respect reduced-motion accessibility settings.

---

# Development Rule

Do not redesign existing pages without a clear reason.

New features must extend the existing design system.

Consistency is more valuable than novelty.

This document is the single source of truth for MEMESCOPE's visual identity.
